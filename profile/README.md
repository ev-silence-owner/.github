### What we build

SILENCE.OBJECTS is an ecosystem by Ewa Tchórzewska (Owner) for **structural behavioral pattern analysis** — a research-driven approach that uses mathematical principles (φ golden ratio, Fibonacci sequences) to observe, classify, and understand behavioral patterns without pathologizing language or clinical framing.

### Core principles

- **φ-Geometry** — Golden ratio as structural foundation for pattern hierarchies, UI proportions, and metric thresholds
- **Zero-PII by design** — No personal identifiable information in event schemas, telemetry, or analytics
- **Neurodiversity-first UX** — `prefers-reduced-motion` respected, no spinning animations, WCAG 2.2 AA, no pure black/white
- **S11 Language Standard** — Structural language only: *pattern, signal, divergence, observation* — never *disorder, symptom, diagnosis*
- **EU AI Act compliance** — Art. 50 transparency, LIMITED RISK classification, full documentation trail
